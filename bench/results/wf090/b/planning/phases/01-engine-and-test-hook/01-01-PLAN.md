<task type="auto">
  <name>Task 1: Engine module</name>
  <files>package.json, js/engine.js</files>
  <action>
Create package.json exactly {"name":"light-cycles","private":true,"type":"module"}. Create js/engine.js with the interfaces listed. Internals: cells in a Uint8Array of width*height (0 free, 1 p1 trail, 2 p2 trail, 3 obstacle). Constructor stores width/height (defaults 64/48), keeps the obstacle list, ignoring entries outside the grid or not [int,int]; sets round=1, scores 0, matchWinner null and calls a private startRound(). startRound(): clear cells, re-place obstacles, place P1 at (floor(W/4), floor(H/2)) dir 'right' and P2 at (W-1-floor(W/4), floor(H/2)) dir 'left', both alive, mark each start cell with its player's trail (overwrites an obstacle there), tick=0, roundOver=false, roundWinner=null, clear pending requests. setDirection(player, dir): return false and do nothing if player not 1/2, dir not in DIRS, roundOver or matchWinner set; return false if dir === OPPOSITE[current dir] where current dir is the direction last moved (start direction before first move); otherwise store it as the pending request (replacing any earlier one) and return true. step(): if matchWinner != null return; if roundOver: round += 1 and startRound(), return. Otherwise for each player: newDir = pending ?? dir; target = pos + DELTA[newDir]; crash if target outside grid or cells[target] != 0 (cells as before this tick). If both targets are equal both crash. Then apply: non-crashed players set dir=newDir, move to target and mark the cell with their trail; crashed players set alive=false and keep position and dir unchanged (do not mark target). Clear pending requests; tick += 1. If any crashed: roundOver=true; exactly one crashed -> the other scores, roundWinner = that player; both -> roundWinner = 0. If a score reaches 3, matchWinner = that player. state() returns a new plain object with the spec shape: grid as height strings using '.', '#', '1', '2'; players array of fresh objects. view(player) returns {width,height,grid (same strings),me,opponent} with fresh {x,y,dir} objects.

<task type="auto">
  <name>Task 2: Baseline chooseMove</name>
  <files>js/ai.js</files>
  <action>
Create js/ai.js exporting pure function chooseMove(view). Build a blocked lookup from view.grid (any char other than '.' is blocked) plus the opponent's possible next cells treated as risky. Candidate moves: the 3 directions that are not the reverse of view.me.dir. A move is safe if its target is inside the grid and free. Score each safe move by flood-fill area (BFS over free cells from the target, counting cells, capped at width*height) ; subtract a penalty (e.g. treat area as half) if the target is adjacent-reachable by the opponent this tick (one of opponent's 3 non-reverse next cells). Return the safe move with highest score, tie-break in the order of view.me.dir first then up, right, down, left. If no safe move exists return view.me.dir. Import nothing from the DOM; may import DELTA/OPPOSITE from ./engine.js. Must run under 20 ms on 64x48.
