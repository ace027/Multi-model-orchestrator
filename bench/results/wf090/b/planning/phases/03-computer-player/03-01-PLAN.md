<task type="auto">
  <name>Task 1: Bots and arenas</name>
  <files>bench/bots.js, bench/arenas.js</files>
  <action>
bench/bots.js, all bots deterministic given their seed, using DELTA/OPPOSITE from js/engine.js, free = in bounds and grid char '.'; 'safe' = not reverse and target free; if no safe move return view.me.dir. random-safe: uniform choice among safe moves with mulberry32(seed). wall-hugger: among safe moves pick the one whose target cell has the most blocked 4-neighbours (walls/out of bounds count as blocked), tie -> keep current dir, then order up,right,down,left. greedy-space: flood-fill (BFS over free cells) area from each safe target, pick max, tie -> current dir then fixed order (a frozen copy of today's js/ai.js logic without the opponent penalty, written here, not imported). territory: for each safe target, BFS distances from the target (me) and from the opponent head simultaneously over free cells (the target counted as blocked for the opponent); score = cells strictly closer to me minus cells strictly closer to the opponent, tie-break by flood-fill area, then current dir. bench/arenas.js: mulberry32; makeArena chooses kind by seed % 3: 'blocks' (6-14 random rectangles 1-6 cells each side), 'walls' (3-6 horizontal or vertical segments 5-20 long, each with a 2-4 cell gap), 'mirrored' (random blocks placed then mirrored point-symmetrically through the centre so both starts are equal). Start cells per spec (P1 (floor(W/4),floor(H/2)), P2 (W-1-floor(W/4),floor(H/2))), the 3 cells ahead of each start in its initial direction, and their 4-neighbours stay free. Reject and regenerate with seed+1000*attempt if the two start cells are not in the same free component. Obstacles deduplicated, all in bounds.

<task type="auto">
  <name>Task 2: Harness and CLI</name>
  <files>bench/harness.js, bench/run.js</files>
  <action>
playRound: new Game({width,height,obstacles}); loop while !game.roundOver and ticks < maxTicks (default width*height): call p1(game.view(1)) and p2(game.view(2)), each timed with performance.now() and pushed to times, setDirection(1,..), setDirection(2,..), step(); winner = state().roundWinner, or 0 when the cap is hit. runBenchmark: for each bot and each round index i, arena = makeArena(seed+i); play once with AI as p1 and bot as p2 (bot = makeBot(name, seed+i)) and once swapped; tally wins/draws/losses from the AI's point of view and score = (wins+0.5*draws)/rounds; collect only the AI's call times for maxMs/p99Ms/meanMs. The ai option is a module path; import it dynamically and use its chooseMove. workers: default Math.max(1, os.availableParallelism()-1); distribute (bot, round, side) jobs over node:worker_threads (the worker imports bench/harness.js playRound and the modules itself, by path); with workers=1 run in-process. run.js parses the flags listed in the interfaces, prints a fixed-width table (bot | P1 W/D/L score | P2 W/D/L score) plus timing and elapsed, --json prints the result object, --md prints a markdown table, --check applies thresholds random-safe>=0.90, wall-hugger>=0.90, greedy-space>=0.75, territory>=0.60 on both sides and maxMs<=10, prints each failing check and exits 1 on any failure.
