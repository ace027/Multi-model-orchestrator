Tests, all driven only by page.keyboard and read through window.tron.state() and the DOM (never call tron.reset/step): (1) waiting: after load wait 500 ms; #message contains 'Space', #score is '0 - 0', state().tick === 0, players at start cells. (2) start + 15 Hz: press Space, wait 600 ms, tick between 5 and 13. (3) steering: after Space press 'w' then wait 150 ms -> players[0].dir 'up'; press 'ArrowRight' wait 150 ms -> 'right'; press 'ArrowLeft' (reverse) wait 150 ms -> still 'right'; also 'a'/'s'/'d' and arrow keys map correctly. (4) pause: Space, wait 200 ms, press 'p', read tick, wait 500 ms, tick unchanged and #message contains 'Paused'; press 'p', wait 300 ms, tick increased. (5) no scroll: in page.evaluate register window keydown listener (after load) that records e.key + e.defaultPrevented; press ArrowUp, ArrowDown, Space; all recorded defaultPrevented true and window.scrollY === 0. (6) rounds and match (timeout 90 s): press Space then 'ArrowUp' so P1 heads into the top wall; poll state every 50 ms; on each roundOver: #score equals `${p1.score} - ${p2.score}` within 200 ms, #message non-empty and not containing 'Paused'; measure ms from roundOver to round incrementing and assert 700..1800 when matchWinner is null; after each new round press 'ArrowUp' again. Stop when matchWinner != null: #message contains 'Space' and contains 'win', winner score is 3. Then press Space, wait 300 ms: #score '0 - 0', round 1, matchWinner null, tick > 0.
