<task type="auto">
  <name>Task 1: Flow state machine with tests</name>
  <files>src/flow.js, tests/flow.test.js</files>
  <action>
Create src/flow.js exporting TICK_MS, CRASH_MS, MAX_TICKS_PER_UPDATE and createFlow(game) per the interfaces. Internal fields: phase ('idle' initially), last (timestamp base, null until started), acc (ms accumulator), crashUntil. key(code, now): if game.mode !== 'realtime' return false without acting. Map steering codes ArrowUp/KeyW->'up', ArrowDown/KeyS->'down', ArrowLeft/KeyA->'left', ArrowRight/KeyD->'right'; when phase==='running' call game.setDirection(1, dir). 'Space': in 'idle' -> phase 'running', last=now, acc=0; in 'matchOver' -> game.reset({width: s.width, height: s.height, ai: true}) using the current state's size, then game.mode='realtime', phase 'running', last=now, acc=0. 'KeyP': 'running'->'paused'; 'paused'->'running' with last=now, acc=0. Return true for every mapped code (Space, KeyP and the 8 steering codes) whatever the phase, false otherwise. update(now): return if game.mode !== 'realtime'. In 'running': acc += now - last; last = now; n = 0; while acc >= TICK_MS and n < MAX_TICKS_PER_UPDATE: game.step(); acc -= TICK_MS; n++; s = game.state(); if s.matchWinner -> phase 'matchOver', break; else if s.roundOver -> phase 'roundEnd', crashUntil = now + CRASH_MS, break. After the loop, if n === MAX_TICKS_PER_UPDATE set acc = 0 (drop backlog). In 'roundEnd': when now >= crashUntil call game.step() once (the engine's reset tick), phase 'running', last = now, acc = 0. 'idle', 'paused', 'matchOver': nothing. message(): exact strings from 02-CONTEXT decisions; roundEnd uses game.state().roundWinner (1 -> 'You win the round!', 2 -> 'Computer wins the round!', null/0 -> 'Draw - both crashed!'); matchOver uses matchWinner (1 -> 'You win the match! Press Space to play again', else 'Computer wins the match! Press Space to play again'). Check what roundWinner holds for a draw in src/engine.js and handle it. Write tests/flow.test.js with node:test + node:assert using the real createGame from src/game.js and chooseMove from src/ai.js, with a manual clock number: idle ignores update and steering, message contains 'Space'; Space starts and update(now + 1000) advances state().tick by 5 at most per call (cap) and exactly floor(elapsed/TICK_MS) for small steps (e.g. 3 calls of TICK_MS each -> 3 ticks); steering request reaches P1 (direction changes after next tick); P pauses (ticks frozen across a 2 s gap) and resume does not catch up; a crash (steer P1 'up' and advance until roundOver) enters 'roundEnd', #score data (state scores) already updated, update before CRASH_MS keeps the round over, update after CRASH_MS performs the reset tick (round+1, tick 0) and phase 'running'; repeat until matchWinner -> 'matchOver' with message containing 'Space' and naming the winner; Space in matchOver resets scores to 0 - 0 and runs; after game.reset() (manual mode) key() returns false and update() changes nothing; Space during running and P during roundEnd/idle do nothing.
