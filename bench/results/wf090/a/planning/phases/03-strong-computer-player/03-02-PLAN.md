<task type="auto">
  <name>Task 1: Search player with Voronoi evaluation</name>
  <files>src/ai.js</files>
  <action>
Rewrite src/ai.js. Copy the view grid into a flat Uint8Array (0 free, 1 blocked) once per call; never touch view.grid. Separation test: BFS from my head over free cells; if no free cell adjacent to the opponent head is reached, use endgame mode (task 2). Otherwise run alternating-move alpha-beta (negamax) over plies: my move then the opponent's reply, resolving each pair simultaneously: both entering the same cell = draw (0), a player entering a blocked cell loses (both = draw); terminal values +/-10000 adjusted by depth so faster wins and slower losses are preferred. Leaf evaluation: two-source BFS from both heads over free cells; score = (cells I reach strictly first) - (cells the opponent reaches strictly first). If the leaf position is separated, evaluate as (my reachable area - opponent reachable area) * 10 so separation outcomes dominate. Iterative deepening over full move pairs (depth 1, 2, 3, ...) with move ordering from the previous iteration's best line, stopping when a global node counter exceeds NODE_BUDGET (a module constant, starting value 4000 leaf evaluations); use the best move of the last fully completed depth. Reverse moves are excluded; exact ties prefer the current heading.

<task type="auto">
  <name>Task 2: Endgame space filling</name>
  <files>src/ai.js</files>
  <action>
Endgame mode (players separated): choose the move that maximises the cells I can still fill. For each safe move compute the checkerboard parity upper bound of fillable cells in the target's reachable component (count cells of each colour; bound = 2*min(black,white) + 1 when the larger colour is the target's colour, else 2*min(black,white)). Then run a depth-first lookahead sharing NODE_BUDGET: at each node, for each safe move, if the move splits the free neighbourhood into more than one component (BFS component count among the new head's free neighbours), score that branch by its largest component's parity bound; otherwise recurse. Pick the move with the highest score; ties go to the move with the most blocked orthogonal neighbours (wall hugging), then to the current heading. Deterministic, same node budget.
