Edge/error cases:
- Policy throws: the call counts as an error and no direction is requested that tick (the cycle keeps going straight)
- Policy returns an invalid string: passed to requestDirection unchanged (the engine ignores it) and counted as an error
- Both cycles crash on the same tick: winner 0 (draw)
- Round hits maxTicks without ending: counted as a draw
- Bots with no safe move return their current dir; random bot on a bad dir returns 'up'
- --rounds odd: the CLI exits 2 with a usage message

Candidate moves are the three non-reverse directions of view.me.dir (all four if dir is invalid). randomBot: uniform random over candidates using rng (may suicide). wallAvoider: random over candidates whose target cell is free; if none, return me.dir; prefers straight with probability 0.5 when straight is safe. floodFillBot: for each safe candidate, BFS-count cells reachable from the target cell with the target and both heads treated as blocked; pick the max, tiebreak straight then rng. territoryBot: for each safe candidate, compute a simultaneous BFS from my target cell and from the opponent's head (opponent distance +1 since it has not moved), score = cells strictly closer to me minus cells strictly closer to the opponent; pick the max, tiebreak by floodFill count then straight. Bots have no special head-on logic. Export BOTS as specified. No state across calls.
