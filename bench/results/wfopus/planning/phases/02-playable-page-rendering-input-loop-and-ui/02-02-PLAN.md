- Match-winning round goes straight to matchOver, no 1 s timer
- enterManual during roundEnd or running cancels all pending ticks and timers; later update() calls never call controller.advance()
- Keys in waiting, matchOver (except Space) and manual do not steer

  <name>Task 1: Session module</name>

  <action>
Create src/session.js (DOM-free, no document/window/requestAnimationFrame/setTimeout) with the interfaces listed. Internals: phase starts 'waiting', message MESSAGES.waiting. handleKey(key, now): map ArrowUp/w/W->up, ArrowDown/s/S->down, ArrowLeft/a/A->left, ArrowRight/d/D->right; ' ' or 'Space' or 'Spacebar' -> space; p/P -> pause. Return true for any of these keys (caller calls preventDefault), false otherwise; in 'manual' still return true for them but do nothing. Steering: call controller.setDirection(1, dir) only in running, paused or roundEnd. Space in waiting or matchOver: controller.newMatch({}) (defaults, ai on), phase running, message MESSAGES.running, nextTickAt = now + tickMs. Pause in running: store remaining = nextTickAt - now and resumePhase 'running'; in roundEnd: remaining = roundEndUntil - now, resumePhase 'roundEnd'; phase paused, message MESSAGES.paused. Pause in paused: restore resumePhase with nextTickAt/roundEndUntil = now + remaining and restore that phase's message (running message, or the round message kept in a variable). update(now): running -> while now >= nextTickAt and ticks < MAX_CATCH_UP: controller.advance(), ticks++, nextTickAt += tickMs; then const s = controller.state(); if s.matchWinner -> phase matchOver, message MESSAGES.match[s.matchWinner], stop; else if s.roundOver -> phase roundEnd, roundEndUntil = now + roundEndMs, message MESSAGES.round[s.roundWinner], stop. If the loop hit MAX_CATCH_UP and still now >= nextTickAt, set nextTickAt = now + tickMs. roundEnd -> when now >= roundEndUntil: controller.advance() (starts the next round), phase running, message MESSAGES.running, nextTickAt = now + tickMs. Other phases: nothing. Return the number of advance() calls. enterManual(): phase manual, message MESSAGES.manual, clear timers. Start with a one-line comment like other src modules.
