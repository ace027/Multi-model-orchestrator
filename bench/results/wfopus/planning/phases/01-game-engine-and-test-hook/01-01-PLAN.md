- export function getState(game) -> {width, height, tick, round, players:[{x,y,dir,alive,score},{...}], grid: string[height] of width chars '.', '#', '1', '2', roundOver, roundWinner: null|0|1|2, matchWinner: null|1|2} — a fresh deep copy every call
- export function getView(game, player /* 1|2 */) -> {width, height, grid (same strings as getState), me:{x,y,dir}, opponent:{x,y,dir}}
Edge/error cases:
- Reverse of the start direction before the first move is ignored (P1 'left', P2 'right').
- right current; requests 'up' then 'left': 'left' is the reverse of current 'right' so ignored; cycle moves up.
- right current; requests 'up' then 'right': last non-ignored is 'right'; cycle keeps moving right.
- Invalid dir ('north', undefined) or player (0, 3) is ignored and returns false.
- Head swap: W=6,H=5 ai-free: P1 (1,2) P2 (4,2); tick 1 -> (2,2),(3,2); tick 2 both target the other's pre-tick cell -> both crash, draw, nobody scores.
- Same target cell: W=9,H=5: P1 (2,2) P2 (6,2); tick 1 -> (3,2),(5,2); tick 2 both target (4,2) -> both crash, (4,2) stays '.', draw.
- A crashed cycle keeps its position and dir; the cell it tried to enter does not become trail; the surviving cycle moves and its target becomes trail.
- Obstacle on a start cell, out of grid, or non-integer is ignored; width/height not an integer >= 2 falls back to the default.
- After matchWinner is set, tick() changes nothing (getState before and after deep-equal).

<task type="auto">
  <name>Task 2: Tick resolution, rounds and match</name>
  <files>src/engine.js</files>
  <action>
Implement tick(game). (a) If matchWinner !== null: return without changes. (b) If roundOver: start the next round: clear all trail cells (keep obstacles), reset both players to startPositions with alive true and pending null, round += 1, tick = 0, roundOver = false, roundWinner = null; scores unchanged; return. (c) Otherwise: for each player, if pending is non-null set dir = pending, then clear pending; compute target = position + DELTAS[dir]. A target crashes if outside the grid, or its pre-tick cell code is non-zero (obstacle or any trail, which includes both current head cells). If both targets are the same cell, both crash. Decide all crashes from the pre-tick cells before writing anything. Then, for each non-crashed player, move to the target and mark it with that player's code; for crashed players set alive = false and leave position untouched (restore dir to the pre-tick dir so 'dir' stays the last moved direction). tick += 1. If any crashed: roundOver = true; if exactly one crashed the other scores and roundWinner = its number; if both, roundWinner = 0; if a score reaches WIN_ROUNDS set matchWinner to that player. Implement willMove(game) = !roundOver && matchWinner === null.
