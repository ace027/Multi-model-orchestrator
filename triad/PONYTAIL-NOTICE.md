# Ponytail notice

Triad's lean rules (option `lean`) are adapted from Ponytail 5.3.3 (https://github.com/DietrichGebert/ponytail), "lazy senior dev mode". Derived material:

- `hooks/lean.ts`: the coder and orchestrator rules (the reuse ladder, never-cut list, `shortcut:` convention, levels lite, full and ultra) from `skills/ponytail/SKILL.md`, and the reviewer rules (a concrete case for every finding, shortcut comments as decisions, the lean categories) from `skills/ponytail-review/SKILL.md`. Reworded for Triad's coders, reviewers and report format.
- `commands/audit.md`: the audit checklist and report format from `skills/ponytail-audit/SKILL.md`, split across Triad's read-only persona runs.
- `hooks/legion/debt.ts`: the shortcut ledger from `skills/ponytail-debt/SKILL.md`, computed in code.

Ponytail's hooks, band, board and benchmark figures were not copied; its code was not run.
